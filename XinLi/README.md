# 心历

公众号：**随心记事**。应用关于页和右键菜单中的公众号名称支持点击复制。

基于本仓库万年历 Swift 版升级的原生 macOS 菜单栏应用。Swift 6、SwiftUI + AppKit，最低 macOS 14。主界面不使用网页、WebView 或 Electron；农历、风景背景、本地日程与任务均可离线使用。

## 编译与运行

推荐使用 Xcode 26.1.1（Swift 6.2.1），GitHub Actions 也固定使用此版本。Xcode 16.4 的 Swift 6.1.2 在 Release 编译时会出现编译器崩溃，暂不支持该工具链；应用最低运行版本仍为 macOS 14。

1. 打开 `XinLi.xcodeproj`。
2. 选择 **XinLi** scheme 和 **My Mac**。
3. 本机开发使用自动签名或 ad-hoc；正式分发请在 Signing & Capabilities 选择自己的团队。
4. ⌘R 运行。应用仅在菜单栏出现；点击日期打开日历，右键打开原生快捷菜单。

命令行：

```sh
cd XinLi
swift build
./scripts/build-app.sh universal
open build/心历.app
```

`build-app.sh arm64` / `x86_64` 可仅编译对应架构。Universal 包支持 Apple Silicon 和 Intel。构建产物为 `build/心历.app`、`build/心历-v1-Universal.zip` 和 `build/心历-v1-Universal.dmg`，不再生成旧应用名的兼容副本。SwiftPM product、模块与可执行文件均名为 `XinLi`，应用显示名为「心历」，包内可执行路径为 `Contents/MacOS/XinLi`。

脚本产物为本机 ad-hoc 签名，尚未经过 Developer ID 签名、公证或 App Store 审核。跨设备发布前需要自行签名和公证；这不影响本机 Xcode 构建运行。

分享时发送完整 DMG 或原始 ZIP，不要直接通过传输工具发送 `.app`，以免内部文件或执行权限被改变。DMG 内含应用、Applications 文件夹快捷入口与安装说明：退出旧版后将应用拖入“应用程序”，再从安装位置启动。DMG 只保留应用结构与权限，不代表已完成公证或通过另一台电脑的安全检查。

对已有完整应用只制作 DMG，无需重新编译：

```sh
./scripts/package-dmg.sh build/心历.app build/心历-v1-Universal.dmg
```

## 已实现

- **菜单栏**：实时日期/时间、周几、可选秒数、图标、农历、节气和当日剩余日程；预设、自定义字段组合及 Unicode 日期格式；全应用统一 IANA 时区，自动处理夏令时。没有秒数字段时按分钟刷新，显示秒时按秒刷新。
- **原生交互**：左键开关日历，打开设置时保留浮窗，便于边调整边预览；点击其他应用自动收起，右键显示新建日程、显示模式、设置及原有节日/纪念日等菜单。NSPopover 跟随菜单栏按钮，按所在屏幕可用高度滚动。
- **风景/迷你模式**：580pt 风景界面与 392pt 迷你界面，共用日期和数据。离线雪山日落、晨雾森林，可导入本地图片；浅色/深色/系统外观、动画开关。
- **毛玻璃与配色**：日历、日期详情与日程分为独立毛玻璃卡片，配合柔和背景渐变、细边框和阴影。提供霜白、海湾、青玉、薰衣草、蔷薇、石墨六套深浅配色；外观设置中可自定义背景色、卡片色、强调色及两层不透明度，即时预览并持久保存。任意强调色自动选择清晰的选中文字，系统“减少透明度”时使用实色卡片。
- **万年历卡片**：日期概览、节气、假期、宜忌、传统历书、时辰和来源使用同一套毛玻璃视觉；吉时标签与可展开的 13 个时段保留真实时间、宜忌和时区换算。常规主题的选中日期采用白字，休/班标记不使用实色底块。
- **Bing 风景**：横幅右上角或“设置 → 外观 → 风景图”中的换图按钮可获取近期不同的 Bing 每日图片；保留版权说明和来源链接，只使用允许下载的条目。图片成功下载后缓存，离线启动仍可显示；下载失败保留原图。刷新需要联网，内置和本地图片仍可离线选择。
- **图片显示范围**：“设置 → 外观 → 风景图 → 显示范围”可选仅顶部横幅、内容区域或整个浮窗。内容区域和整窗背景支持调节图片浓度，Bing、内置和自定义图片共用此选项；迷你模式也可用全窗背景，并在底栏提供换图和 Bing 来源入口。默认保留顶部横幅，设置立即生效并在重启后恢复。
- **极简模式**：在“设置 → 外观 → 界面模式”或状态栏右键菜单选择“极简”，同一面板只显示月历与所选日期的农历、干支和宜忌。完整黄历可原地展开；不显示风景横幅、标签页、日程和新建日程入口。与其他模式共用日期、主题及数据。
- **卡片与布局**：“设置 → 外观 → 卡片与布局”可选择毛玻璃/简洁卡片，以及紧凑/标准/宽松密度。密度调整留白、间距与月历行高，不缩小字体。默认隐藏滚动条，仍可用滚轮/触控板滚动；打开“显示滚动条”可恢复原生指示器。
- **字体与字号**：“设置 → 外观 → 字体与文字大小”可搜索并选择本机已安装字体，或使用系统默认；文字缩放支持 30%–120%，只影响日历、黄历和日程等应用面板。重新打开列表时自动定位当前字体并保留勾选；鼠标移过字体列表或滚动列表时，实时预览鼠标所在行的字体；点击保存，关闭列表后恢复已保存的字体。预览不影响状态栏，其字体与字号始终保持系统默认。大字号会增加日历行高，日期摘要按可用宽度分行；设置自动保存，支持恢复默认，缺失字体回退系统字体。
- **整行展开**：万年历的历法说明、完整时辰列表、逐时辰详情等展开项，文字、箭头及同行空白处均可点击；展开内容中的链接和文字选择保持独立。
- **快速选日**：万年历和日程页顶部日期导航跟随当前主题，点击日期可通过月历或直接输入年月日跳转（1901–2099 年）；确定后更新选择，取消保留原日期，使用应用设置的时区。
- **顶部遮罩**：风景模式下，“设置 → 外观 → 透明度与动画 → 顶部遮罩不透明度”独立控制问候区的遮罩，0% 清除，100% 最强。三种图片显示范围均生效，文字和按钮不受此透明度影响；默认 45%，设置自动保存。
- **日历**：1901–2099 年、42 格月视图、周一/周日起始、跨月日期、今天与选中日期的不同样式、日程彩色圆点、年份/月选择、回到今天。支持鼠标拖动、触控板或 Magic Mouse 横向滚动，以及有方向的翻月动画。
- **键盘**：浮窗内方向键移动一天/一周，Option+左右键切换月份，回车回到今天，⌘N 新建日程。编辑文本时不拦截方向键。
- **万年历**：Foundation 中国历法，闰月、大小月、农历节日、干支生肖、24 节气、已载入年份的放假与调休标识。今天与交节时刻使用应用时区，交节时刻与数据覆盖说明见下方。
- **传统黄历**：lunar-go v1.4.6 的 1901–2099 年离线宜忌、冲煞、彭祖百忌与时辰条目；13 个传统时段换算至应用时区显示，跨日注明日期，分别保留早子与晚子。
- **本地日程**：SwiftData 持久化；创建、读取、编辑、删除；全天、标题、时间、地点、备注、会议 HTTPS 链接、颜色、提前提醒；每天/周/月/年重复、自定义周期间隔和周几、重复截止日，单次例外或整个本地系列编辑。
- **系统日历**：EventKit 全访问权限经用户点击后请求；选择可见日历、读取及在可写日历中创建/编辑/删除；系统变更刷新、权限撤销和只读日历提示。拒绝权限后本地功能仍可用。
- **日程面板**：当日时间线、未来 7/30 天、明天、本周和自定义范围；事件详情/会议入口；任务创建、编辑、删除、截止日期、优先级、完成/取消完成与排序统计。
- **通知**：经用户授权后使用 UserNotifications；本地事件及任务提醒预先排程，可关闭并取消待发通知。系统事件使用 EventKit alarm，由系统日历负责提醒。
- **设置**：外观、状态栏、万年历、日程、通用五类，修改即时应用并持久保存；登录自动启动使用 SMAppService。所有中文周名使用“周一…周日”。

## 使用说明

首次启动不主动弹出日历/通知权限请求。在 **右键菜单 → 设置 → 日程** 中点击“连接 Apple 日历”或“允许提醒通知”时才请求对应权限。

“新建日程”默认保存在本机。连接系统日历后，可以在编辑器中选择有写入权限的日历。日程颜色由本地用户选择或跟随系统日历颜色，不从标题关键词推断。点击现有日程可查看和修改；删除有二次确认。

所有界面共用一个应用时区，包括状态栏、日历“今天”、问候、交节时刻、黄历时段、日程列表与编辑器、任务截止日期及自定义日期。设置位置：**右键状态栏 → 设置 → 通用 → 应用时区**，也可以在状态栏显示设置中修改同一选项。已有状态栏时区优先保留；首次安装跟随系统。

更改立即更新今天高亮；如果原来正在查看今天，跨月或跨年也会切换到新时区的当天月份；正在查看的其他选中日期会保留。修改会持久保存，重新启动后恢复。

点击月历标题打开年月选择面板：12 个月网格、12 年分页以及直接输入四位年份（1901–2099）。Return 确认、Escape 取消。选择年份时不改变当前日期，确认月份后一次跳转。

日历浮窗按当前内容自动增高或缩短；超过所在屏幕可用高度时改为滚动。切换页面、模式、年份选择面板和展开详情时都会重新测量。

日历七列铺满内容区，两侧留白为迷你 14pt、风景 18pt；农历、日程时间和详情使用更易读的字号。日期摘要卡同步显示所选日期的真实黄历宜忌，迷你模式各取前三项，风景模式各取前四项；点击“完整黄历”打开当日万年历详情，关闭黄历显示时摘要也随之隐藏。

中国农历及无交节时刻年份的节气日期始终采用北京时间历法规则。选择一个公历日期，会查看这个日期在中国历法中的对应农历；不会把北京日期算法当作另一地区的传统历法。

本地重复事件按创建时保存的时区保持当地钟点，支持夏令时变化。全天事件按日期显示，切换显示时区不把它拆成两天。切换时区仅影响展示，不改已保存事件的绝对时刻。

## 数据与权限

Xcode 工程启用 App Sandbox，声明：

- `com.apple.security.personal-information.calendars`：EventKit 日历访问。
- `com.apple.security.files.user-selected.read-write`：导入用户选中的风景图，以及延续旧项目的纪念日文件导入/导出。
- `com.apple.security.network.client`：延续原项目可选假日数据更新。

Info.plist 提供 `NSCalendarsFullAccessUsageDescription`（macOS 14+）和兼容的日历说明；不读取 Apple ID、账户密码，不请求通讯录、定位或提醒事项权限。用户拒绝或撤销日历权限时，应用显示真实状态，不声称写入成功。通知权限由系统单独管理，专注模式或系统通知设置可能影响展示。

SwiftPM 打包脚本延续旧版本的非沙盒分发方式，保留 Bundle ID `com.zfdang.WanNianLiSwift` 和旧数据位置，方便原项目升级。Xcode 的沙盒构建使用系统容器，和非沙盒版本的数据位置不同，**不自动迁移容器外旧数据**。正式选择一种发布方式后应保持一致；在切换前保留原数据。

非沙盒数据：`~/Library/Application Support/WanNianLi/Agenda.store` 及原项目节日/纪念日文件；设置在对应 Bundle ID 的 UserDefaults；自定义风景复制到 `~/Library/Application Support/ChronoCal/custom-background.jpg`。沙盒版本使用容器下相应 Application Support 与 preferences。开发时可用 `XINLI_DATA_DIR` 指定独立数据目录；优先读取新变量，同时兼容旧变量 `WANNIANLI_DATA_DIR`。

Bing 图片及版权元数据存放在 `~/Library/Application Support/ChronoCal/Bing/`，属于运行时缓存，不包含在应用包或项目 MIT 资源许可内。应用通过 HTTPS 访问 Bing 图片档案和图片地址，不发送日历、日程或任务数据。

## 准确性与明确限制

1. 日历可浏览 **1901–2099 年**，边缘月份灰色格可显示相邻边界日期但不可越界选中。保留原项目历法实现和 ICU 修正。
2. **2025–2027 年**有离线交节时刻。72 个计算值与香港天文台官方分钟表逐项比较，最大差约 59.5 秒；界面显示“约”并取整到分钟。其他年份仅提供北京时间的节气日期，不虚构时刻。算法、历史核验统计、资源生成步骤和许可证见 [DATA-SOURCES.md](DATA-SOURCES.md)。
3. 假期数据当前载入 **2020–2026 年**的正式调休安排。未公布/未载入年份会提示未知；传统节日不等于法定放假。此次修正了 2020 年春节延长假期中的 2 月 1 日标记。
4. **黄历是传统民俗数据，并非官方历法标准或科学预测。** 采用 MIT 许可的 lunar-go **v1.4.6**，固定提交 `dd82a5bc13f4e08417cb78b58f7a7fd90c1fd649`；离线范围为 **1901–2099 年**。资源缺失、损坏或日期超出范围时明确显示不可用，不编造宜忌。该模块不替换 Foundation 农历、已核验的交节时刻或官方放假安排。
5. 系统重复日程提供“仅此日程”与“此日程及后续”，遵循 EventKit 的 `.thisEvent` / `.futureEvents` 语义；不把“后续”误称为包含过去的整个系列。本地重复日程支持整个系列。
6. 本地通知预排未来一年内最近 **60 条**，在应用启动、唤醒/激活、跨日和数据刷新时补充；存在超过 60 条时，还会在最早提醒触发后自动补排。关闭应用后已经排程的通知仍交给 macOS，长期不启动不会无限补充未来提醒。
7. 简体中文为当前界面语言；未接入天气、Apple 提醒事项、外部云账户或跨设备同步。任务仅保存在本机。快捷键为浮窗内快捷键，不是全局热键。
8. 运行时不加载第三方计算库，农历与黄历查询可离线完成。生成交节数据的开发脚本使用固定版本 MIT Astronomy Engine；黄历再生成工具在 `Tools/LunarGoExporter/` 保留固定版本 MIT lunar-go 源码。应用资源随 Xcode/SwiftPM 打包，正常构建与运行不需要 Go、Python 或联网计算；Go 只在重新生成黄历资源时需要。
9. EventKit 真实账户读写、系统授权后的实际通知投递、多实体显示器边缘、VoiceOver 完整流程须在用户授权的设备上验收；历史验证未操作用户真实日历或代为授权。

### 心历图标

新图标采用浅色日历页、珊瑚红心形与淡蓝紫背景；源文件为 `scripts/generate-icon.swift`，无字体或在线素材依赖。可重新生成标准 16–1024 像素资源：

```sh
swift scripts/generate-icon.swift build/HeartCalendar.iconset
iconutil -c icns build/HeartCalendar.iconset -o Resources/ChronoCalIcon.icns
cp build/HeartCalendarIcon.png Resources/HeartCalendarIcon.png
```

`ChronoCalIcon.icns` 保留原资源文件名以兼容工程引用，内容已是心历新图标。
